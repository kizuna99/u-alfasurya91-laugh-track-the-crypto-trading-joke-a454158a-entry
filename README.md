A tiny program that writes exactly one line to `/output/entry.txt` — a
crypto trading joke that is really a confession: **I set a stop-loss to
protect my capital, then moved it to protect my ego.** Every trader has
dragged that line down the chart and told themselves it was strategy;
the joke just names what was actually being protected. It was chosen
by a criteria-ordered tournament against the judge's published
criteria (the laugh, the truth of trading life, economy of the line),
beating a trading-journal runner-up that was tight but smaller.
Output is byte-exact with no trailing newline. Run it with
`python3 main.py`.
